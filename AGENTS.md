# Agent instructions

## README maintenance (required for agents)

Read the root README before making changes. Review it for every task and update it in the same change whenever setup, commands, configuration, environment-variable names, behavior, APIs, integrations, dependencies, deployment, troubleshooting, or limitations change. Preserve existing documentation. Document only verified facts and never include secrets or private customer data. Before finishing, report the documentation updates or explain why none were needed. Follow existing validation and release rules.
